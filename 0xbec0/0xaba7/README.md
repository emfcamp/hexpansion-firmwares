# Bat detector

A hexpansion with a high-frequency microphone and headphone jack, primarily for recording bats, but also for all of your sound input and output needs. See [https://codeberg.org/jna_sh/batspansion](https://codeberg.org/jna_sh/batspansion) for more information.

Produced by Bodgeham-on-Wye Electronic Consulting Co-Operative, in cooperation with Tympanl.
